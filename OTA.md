<a id="requirements"></a>
## Первая установка и разделы flash

**Первую версию с веб-интерфейсом нужно один раз залить по USB.** Ранее
загруженная версия с BLE не умеет принимать OTA-обновления.

Проверьте таблицу разделов при первой заливке:

| Плата / схема | OTA |
|---|---|
| ESP32 Dev Module, flash 4 МБ, Default 4MB with spiffs | Два раздела приложения по 1 310 720 байт; поддерживается |
| Minimal SPIFFS (1.9MB APP with OTA/128KB SPIFFS) | Поддерживается; новый образ должен помещаться в раздел |
| Huge APP / No OTA | Не поддерживается: потребуется прошивка по USB с таблицей для OTA |

Обновление записывает только приложение в свободный OTA-раздел. Оно не меняет
загрузчик, таблицу разделов и размер flash. Новую прошивку собирайте для той же
модели ESP32, объёма flash и таблицы разделов, которые установлены на устройстве.
Для смены таблицы разделов используйте USB.

<a id="build"></a>
## Получить файл новой прошивки

Скачайте новую версию проекта. Библиотеки и настройки описаны в
[INSTALL.md](INSTALL.md#dependencies).

### Arduino IDE

Откройте `bk/bk.ino`, выберите плату и параметры установленной прошивки,
затем **Sketch → Export Compiled Binary / Скетч → Экспорт бинарного файла**.
Найдите **bk.ino.bin** в каталоге результатов сборки, обычно внутри
`bk/build/` в Arduino IDE 2.x. Точный путь зависит от версии IDE и виден
в выводе компиляции.

### Arduino CLI

Для проверенной ESP32 Dev Module со стандартной таблицей разделов,
из корня репозитория:

```powershell
arduino-cli compile --fqbn esp32:esp32:esp32 --export-binaries .\bk
```

Файл для обновления: **`bk/build/esp32.esp32.esp32/bk.ino.bin`**.
Каталог `bk/build/` исключён из Git. Для другой конфигурации используйте
соответствующий FQBN и параметры; имя каталога результатов может отличаться.

Не выбирайте `*.bootloader.bin`, `*.partitions.bin`, `*.merged.bin`, `.elf`
или архив проекта. Нужен отдельный бинарный файл **приложения**. Если обновляете
с телефона, заранее перенесите `bk.ino.bin` в его файлы; интернет в сети ESP32
не предоставляется.

<a id="upload"></a>
## Подключиться и загрузить

1. Удерживайте кнопку устройства на GPIO13 при включении / EN / RESET примерно
   3 секунды, до экрана **NEXIA SETUP / OTA**, затем отпустите.
2. Подключитесь к сети **Nexia-Setup-XXXX** с OLED. Пароль — строка **Pass**.
3. Откройте **[http://192.168.4.1](http://192.168.4.1)**. Имя пользователя —
   **admin**, пароль — тот же, что для Wi-Fi. Подробности подключения — в
   [инструкции настройки времени](TIME_SYNC.md#connection).
4. В блоке **Обновление прошивки** выберите **bk.ino.bin** и нажмите
   **Загрузить прошивку**. JavaScript должен быть включён.
5. Дождитесь окончания. На OLED отображаются **UPLOADING** и процент приёма.
   Процент приёма ещё не означает, что финальная проверка образа завершилась.
   Сохраняйте питание и подключение до сообщения браузера об успешной записи.
6. После успешной проверки ESP32 перезапустится. Отпустите кнопку устройства,
   чтобы загрузился обычный режим часов и OBD. Wi-Fi-сеть настройки исчезнет.
7. При следующем входе в режим настройки пароль будет новым.

ELM327 в режиме настройки не опрашивается. Часы RTC продолжают идти; время
можно выставить на этой же странице кнопкой из [TIME_SYNC.md](TIME_SYNC.md).
Через 10 минут бездействия выполняется выход в обычный режим.

<a id="recovery"></a>
## Проверки и восстановление

- Изменяющие запросы требуют авторизации и заголовка Origin страницы ESP32.
  Сеть защищена случайным 12-символьным паролем, показанным на OLED, и доступна
  только после физического входа в режим настройки.
- Сервер проверяет размер по фактическому свободному OTA-разделу, принимает
  один файл приложения за запрос и сверяет полученное число байтов с заявленным.
- Новый загрузочный раздел выбирается только после полного HTTP-запроса
  и успешного завершения `Update.end()`. Проверка бинарного образа выполняется
  библиотекой Update / ESP-IDF.
- При ошибке, неполной передаче или обрыве соединения запись отменяется.
  Перезапуск по успеху не выполняется, можно открыть страницу и повторить загрузку.
  После такой ошибки прежнее приложение остаётся выбранным для загрузки.
- При сообщении **NO OTA SLOT** установите таблицу для OTA по USB по
  [INSTALL.md](INSTALL.md#arduino-ide). Браузер не меняет таблицу разделов.
- Если RTC отсутствует, установка времени недоступна, но режим OTA продолжает
  работать. Он включается до запуска OBD.

Автоматический откат при ошибках **уже запустившейся** новой прошивки не
реализован. Успешная проверка образа не проверяет прикладную логику, распиновку
или соответствие файла этому проекту. Если новая версия не запускается,
используйте USB для восстановления. Отключать питание во время записи не следует.

<a id="hardware-check"></a>
## Аппаратная проверка

Перед использованием на автомобиле проверьте на своей плате:

1. Обычный запуск без кнопки, затем вход в режим настройки с кнопкой.
2. Подключение с телефона / ПК и установка времени, чтение RTC обратно.
3. Загрузка корректного образа, автоматический перезапуск и работу часов / OBD.
4. Повторное обновление после первого: оба OTA-раздела должны работать по очереди.
5. Отказ на неподходящем / слишком большом файле и возможность повторной загрузки.
6. Обрыв Wi-Fi во время передачи: прежняя прошивка должна оставаться выбранной;
   после повторного подключения должна работать повторная загрузка.
7. Выход кнопкой **Вернуться к часам** и автоматический выход при бездействии.

Локальные тесты обработчиков описаны в [tests/README.md](tests/README.md).
Они не заменяют запись flash и проверку с реальным браузером / ESP32.

Реализация использует штатные
[Update / WebServer Arduino ESP32](https://docs.espressif.com/projects/arduino-esp32/en/latest/ota_web_update.html)
и [OTA-разделы ESP-IDF](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/api-reference/system/ota.html).
