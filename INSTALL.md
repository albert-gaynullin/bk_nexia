# Сборка и заливка прошивки ESP32

[Описание устройства и оглавление](README.md) · [Установка времени с телефона](TIME_SYNC.md) · [Обновление по Wi-Fi](OTA.md)

Инструкция относится к скетчу [bk/bk.ino](bk/bk.ino) и исходникам в папке `bk`. Проверенная
конфигурация — обычная ESP32 Dev Module с flash 4 МБ и Arduino ESP32 core 3.3.5.
Для другой платы выберите её модель и фактический объём flash.

<a id="requirements"></a>
## Что понадобится

- Плата ESP32 и USB-кабель с передачей данных.
- Компьютер с Arduino IDE 2.x либо Arduino CLI.
- Драйвер USB–UART вашей платы, если она не появляется в списке портов.
- Подключённые OLED SSD1306, RTC PCF8563 и кнопка — по
  [таблице подключений](README.md#wiring-table).

Для первого запуска достаточно USB-питания. Wi-Fi ELM327 понадобится для
проверки автомобильных показаний; часы и веб-настройку можно проверить без него. Первую веб-версию залейте по USB;
дальше доступно [обновление по воздуху](OTA.md).

<a id="files"></a>
## Открытие проекта

Склонируйте репозиторий или скачайте ZIP с GitHub и распакуйте его.
Выберите ту же ветку, в которой открыта эта инструкция, чтобы получить
соответствующую ей структуру файлов.
Каталог скетча уже подготовлен в репозитории:

```text
bk_nexia/
├── bk/
│   ├── bk.ino
│   ├── DevicePortal.h
│   ├── DevicePortal.cpp
│   └── LocalTime.h
├── INSTALL.md
├── TIME_SYNC.md
└── README.md
```

Откройте **[bk/bk.ino](bk/bk.ino)** через **File → Open / Файл → Открыть**
в Arduino IDE. Создавать папки, копировать файлы и переименовывать каталог
репозитория не требуется: имя скетча уже совпадает с именем папки `bk`.
Сам каталог репозитория после скачивания ZIP может называться иначе — это
не мешает открытию скетча.

Arduino IDE автоматически собирает `.cpp` из папки скетча. Сохраняйте всю
папку `bk`, включая `DevicePortal.h`, `DevicePortal.cpp` и `LocalTime.h`.
BLE заменён веб-интерфейсом: NimBLE-Arduino и `build_opt.h` больше не нужны.

Перед сборкой проверьте в [bk/bk.ino](bk/bk.ino) параметры своего ELM327:

| Параметр | Значение в проекте |
|---|---|
| Wi-Fi SSID | `WiFi_OBDII` |
| Пароль | Не задан; используется открытая сеть |
| IP адаптера | `192.168.0.10` |
| TCP-порт | `35000` |
| Протокол ELM327 | `'5'` |

Если сеть адаптера защищена паролем, вызову `WiFi.begin(ssid)` потребуется
передать и пароль. PID топлива и его пересчёт относятся к конкретному автомобилю;
подробности — в [описании параметров OBD](README.md#obd-parameters).

<a id="dependencies"></a>
## Версии зависимостей

Эти версии использованы при успешной проверке сборки:

| Пакет / библиотека | Версия |
|---|---|
| esp32 by Espressif Systems | 3.3.5 |
| Adafruit GFX Library | 1.12.5 |
| Adafruit BusIO | 1.17.4 |
| Adafruit SSD1306 | 2.5.16 |
| ELMDuino | 3.4.1 |
| RTClib | 2.1.4 |

WiFi, Wire, SPI, FreeRTOS, WebServer и Update входят в пакет ESP32.
Библиотеки BLE / NimBLE для новой версии не нужны.

<a id="arduino-ide"></a>
## Сборка и заливка через Arduino IDE

### 1. Установить поддержку ESP32

1. Установите [Arduino IDE](https://www.arduino.cc/en/software).
2. В настройках IDE добавьте в поле **Additional Boards Manager URLs**
   (дополнительные ссылки менеджера плат) адрес стабильного пакета Espressif:

   ```text
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```

3. В менеджере плат найдите **esp32 by Espressif Systems**, выберите версию
   **3.3.5** и установите её.
4. В менеджере библиотек установите библиотеки из
   [таблицы зависимостей](#dependencies), выбирая указанные версии.
   Если IDE предлагает установить зависимости Adafruit, согласитесь.

### 2. Открыть скетч и выбрать настройки

Откройте [bk/bk.ino](bk/bk.ino), сохранив остальные исходники папки `bk` рядом.
Подключите плату по USB и задайте настройки:

| Настройка | Для проверенной ESP32 с flash 4 МБ |
|---|---|
| Board | `ESP32 Dev Module` |
| Flash Size | `4MB (32Mb)` |
| Partition Scheme | `Default 4MB with spiffs (1.2MB APP/1.5MB SPIFFS)` |
| Port | Порт подключённой платы |

Таблица должна содержать два OTA-раздела. Вариант **Huge APP / No OTA**
не подходит для обновления по воздуху. Остальные настройки можно оставить стандартными. У другой модели ESP32
названия и допустимые значения могут отличаться. Ранее использованная таблица
`Minimal SPIFFS` тоже вмещает прошивку; менять её только ради оптимизации не нужно.

### 3. Собрать и залить

1. Нажмите **Verify / Проверить** и дождитесь успешной сборки.
2. Закройте другие программы, которые занимают COM-порт платы.
3. Нажмите **Upload / Загрузить** и дождитесь завершения записи.
4. Если автоматический вход в загрузчик не сработал и IDE ожидает соединения,
   удерживайте **BOOT** до начала записи, затем отпустите. После загрузки при
   необходимости нажмите **EN / RESET**.
5. Откройте монитор порта со скоростью **115200 бод** и выполните
   [проверку первого запуска](#first-start).

<a id="arduino-cli"></a>
## Сборка и заливка через Arduino CLI

Ниже команды для PowerShell. Установите
[Arduino CLI](https://docs.arduino.cc/arduino-cli/installation) и убедитесь,
что команда `arduino-cli version` выполняется. Откройте терминал в корне проекта.

### 1. Установить пакет платы и библиотеки

```powershell
$esp32Index = 'https://espressif.github.io/arduino-esp32/package_esp32_index.json'
arduino-cli core update-index --additional-urls $esp32Index
arduino-cli core install esp32:esp32@3.3.5 --additional-urls $esp32Index
arduino-cli lib update-index
arduino-cli lib install "Adafruit GFX Library@1.12.5" "Adafruit BusIO@1.17.4" "Adafruit SSD1306@2.5.16" "ELMDuino@3.4.1" "RTClib@2.1.4"
```

Продолжайте после успешного завершения каждой команды.

### 2. Собрать из каталога репозитория

```powershell
$buildDir = Join-Path $env:TEMP 'bk_nexia_build\build'
arduino-cli compile --fqbn esp32:esp32:esp32 --build-path $buildDir .\bk
```

Успешная сборка помещается в стандартный раздел приложения 1 310 720 байт.
Точные результаты и сравнение версий — в [README](README.md#memory).

### 3. Найти порт и залить

```powershell
arduino-cli board list
```

Найдите порт своей платы. В следующей команде **замените `COM5` на него**.
Выполняйте загрузку только после успешной сборки из предыдущего шага,
в том же окне PowerShell:

```powershell
arduino-cli upload --fqbn esp32:esp32:esp32 --port COM5 --input-dir $buildDir .\bk
```

Команда `upload` записывает готовые файлы и сама скетч не компилирует.
Если меняли любой исходник в папке `bk`, сначала снова выполните сборку.
Для монитора порта после загрузки:

```powershell
arduino-cli monitor --port COM5 --config baudrate=115200
```

Здесь тоже замените `COM5` на порт платы. Завершить монитор можно `Ctrl+C`.

<a id="first-start"></a>
## Проверка после заливки

1. После заставки `NEXIA` должны появиться часы. При потере питания RTC
   прошивка устанавливает время компиляции; выставьте точное время через
   [веб-интерфейс телефона / ПК](TIME_SYNC.md#write-time).
2. Нажмите кнопку: должен открыться экран OBD. Без ELM327 он показывает
   подключение или недоступность адаптера; кнопка должна возвращать часы.
3. Включите ELM327 и проверьте автоматическое подключение, затем его
   восстановление после отключения и повторного включения адаптера.
4. Проверьте показания на автомобиле. Отсутствующее значение выводится как `--`;
   отрицательную температуру проверяют в подходящих условиях либо на симуляторе.
5. Войдите в режим настройки: удерживайте кнопку GPIO13 при включении /
   перезапуске примерно 3 секунды, до экрана **NEXIA SETUP / OTA**, затем отпустите.
6. Подключитесь к Wi-Fi с OLED, откройте `http://192.168.4.1`, введите имя
   `admin` и пароль с OLED. Установите время кнопкой на странице и вернитесь
   к часам. Подробности — в [TIME_SYNC.md](TIME_SYNC.md).
7. Для следующих обновлений используйте [OTA.md](OTA.md). Заливается только
   `bk.ino.bin`; новые разделы через браузер не устанавливаются.

Сборка и локальные тесты обработчиков выполняются на компьютере. USB-заливка,
чтение/запись RTC, Wi-Fi и OTA на конкретной плате требуют аппаратной проверки.

<a id="troubleshooting"></a>
## Решение проблем

| Проблема | Что проверить |
|---|---|
| Не найден `DevicePortal.h` или `LocalTime.h` | Скачана ли целиком папка `bk`, а не один файл `.ino` |
| Не найдены `ELMduino.h`, `RTClib.h` или заголовки Adafruit | Установлены ли все [зависимости](#dependencies) |
| IDE предлагает создать каталог скетча | Открывайте `bk/bk.ino`, сохранив структуру папки `bk` из репозитория |
| Прошивка не помещается | Правильная ли плата и таблица разделов; используются ли исходники новой веб-версии |
| Плата не видна в списке портов | Кабель с передачей данных, USB-порт и драйвер USB–UART платы |
| `Failed to connect` при загрузке | Выбран ли верный порт, свободен ли он; попробуйте вход в загрузчик через BOOT |
| Сообщение RTC unavailable | Подключение PCF8563; веб-обновление доступно и при отсутствии RTC |
| Пустой дисплей | Питание, SDA/SCL, адрес OLED `0x3C` и [схема подключения](README.md#oled) |
| Нет связи с ELM327 | SSID, пароль, IP, TCP-порт и поддержка выбранного протокола адаптером/автомобилем |
| Не получается изменить время | Раздел [решения проблем веб-настройки](TIME_SYNC.md#troubleshooting) |
